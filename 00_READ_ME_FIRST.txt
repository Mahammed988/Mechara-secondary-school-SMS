🎓 5 ROLES EXPLAINED (30 seconds):
──────────────────────────────────
1. ADMIN
   ✓ Full access
   ✓ Approves student registrations (KEY ROLE)
   ✓ Manages users, system settings

2. TEACHER
   ✓ Mark attendance for own class
   ✓ Enter grades for own class
   ✗ Cannot see other classes

3. REGISTRAR
   ✓ Register new students
   ✓ Manage student info
   ✗ Cannot approve (admin does that)

4. FINANCE
   ✓ Record fee payments
   ✓ View fee reports
   ✗ Nothing else

5. STUDENT
   ✓ View own grades, attendance, fees
   ✗ Cannot access until admin approves


🔄 STUDENT WORKFLOW (45 seconds):
──────────────────────────────────
1. Student clicks "Student Self-Registration"
2. Fills form (name, email, username, password, phone)
3. Submits → Status: PENDING
4. Admin logs in → Goes to "Student Approvals"
5. Admin clicks "Approve"
6. System creates account automatically
7. Student can now login


✅ KEY DIFFERENCES (As You Requested):
───────────────────────────────────────
✓ ADMIN can approve students (exclusive)
✓ TEACHER limited to own class (not all classes)
✓ REGISTRAR can register but NOT approve
✓ FINANCE does ONLY fees
✓ STUDENT needs admin approval first

Each role is completely different!
